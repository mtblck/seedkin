Beastie Stable

Seeded monster avatars: blobs, ghosts, boxes, tall and wide bodies with one to three eyes, fangs, horns and wings, in eight hides. Try them in the playground.

Use

import { beastie, beastieDataUri } from 'seedkin/beastie';

const svg = beastie(user.id);
const src = beastieDataUri(user.id, { size: 40 });

The seed is salted, so one id's Botling, Snoot and Beastie are unrelated.

Options

beastie() takes the same options as snoot(): shape, palette (an index into Beastie's own eight PALETTES, or a palette object such as one of its HOLIDAY_PALETTES), size, detail, showGrid, look, frame, background, animate and title (default 'Monster avatar'). Below 40px it draws a simpler 9x9 Beastie from the same traits.

Animation

With animate: true a Beastie hovers, blinks and talks, its horns or antennae wobble and its arms or wings twitch. Below 40px it only blinks and hovers.

Exports

HOLIDAY_PALETTES, traits, resolveTraits, grid, smallGrid, BODIES, EYES, MOUTHS, TOPS, SIDES and SHAPES are exported as for Botling (see Advanced).
